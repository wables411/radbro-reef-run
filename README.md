# RADBRO REEF RUN

Static build of Reef Run (the radbro.fun edition) — an underwater endless
swimmer. Dodge the reef, haul out the trash.

Playable: https://wables411.github.io/radbro-reef-run/

This repo contains **only the compiled game** (HTML/JS/CSS + 3D assets) so it
can be served over GitHub Pages and embedded by radbro.fun. Source lives in the
private lawb2 repo under `src/radbroStandalone/`; rebuild with
`npm run build:radbro`.
